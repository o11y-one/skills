# Changelog

All notable changes to this repo.
Versions follow [Semantic Versioning](https://semver.org); [AGENTS.md](AGENTS.md#versions) says what counts as a patch, minor or major change.

## 1.0.0

- The `o11y-one-setup` skill: detect, recipe, key, apply, load order, verify and troubleshooting, with 14 references.
- The Claude Code plugin `o11y-one`, which bundles the o11y-one MCP server with the skill.
- CI checks for frontmatter, names, reference index sync, links and anchors, versions, and the plugin manifests.
- An eval harness with fixture apps, a mock MCP server and an OTLP sink.
